                 How to Use ASCII Map Builder
            

            
            

                
1. Create Tile Palette: Customize your tiles in the left sidebar. Each tile combines a background color with an overlay ASCII symbol.

                
2. Paint Canvas: Click or drag across the grid with the Paint Tool. Use the Fill Bucket to flood fill regions.

                
3. Export Map: Click Export Map to copy standard ASCII characters for your game files or JSON to save work for later.

                 How to Use ASCII Map Builder
            

            
            

                
1. Create Tile Palette: Customize your tiles in the left sidebar. Each tile combines a background color with an overlay ASCII symbol.

                
2. Paint Canvas: Click or drag across the grid with the Paint Tool. Use the Fill Bucket to flood fill regions.

                
3. Export Map: Click Export Map to copy standard ASCII characters for your game files or JSON to save work for later. The Bakemon maps.js tab gives you a tiles: block and a matching rotations: block, ready to paste straight into data/maps.js.


                


                
Seeing the real art

                
Press Sprites in the canvas bar to swap the coloured letters for the actual pictures out of art/tileset.png. The dropdown beside it picks which legend your letters are read with — r is a rock outdoors and a rug indoors, so this matters. Letters that legend doesn't know (a map's own places, like a door) stay as letters.

                
If the button is greyed out, the tool can't reach the game's files. Keep it in gameguy/tools/, and open it through a local web server rather than double-clicking the file.

                
Got a new tilesheet you want in here? Run it through tools/sheet_importer.html first — it names the cells for you and writes the data/tiles.js entries. Once they're in, this tool picks them up on reload.


                


                
Turning tiles

                
Pick the Turn tool and click a tile to spin it a quarter turn clockwise: 90°, 180°, 270°, then back to square. Right-click or shift-click goes the other way. Turned cells get an amber corner tag and an amber outline.

                
Only the object turns, never the ground beneath it, and turning changes nothing but the picture — a solid tile stays solid. Painting something new over a turned cell clears its turn.

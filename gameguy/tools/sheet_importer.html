Sheet Importer

Turn any tilesheet PNG into data/tiles.js entries, without counting squares.

How this works

  1. Pick a PNG tilesheet below. Nothing is uploaded anywhere — it's read on this machine.
  2. Set how big one tile is. For this game that's 32. If the cells look wrong, it's this number.
  3. Type a name under each picture you want. Skip the ones you don't. Tab moves you along.
  4. Copy the code at the bottom into data/tiles.js, and drop the PNG into gameguy/art/.
